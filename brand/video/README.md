# Ugent brand film

A 1 min 50 s landscape (1920×1080, 30 fps) film with 3D phones showing real Ugent screens, in four parts:
the intro, **Free** (white), **Pro** (deep navy) and **Team** (sky), then a closing carousel with the prices.
The music is original, generated by `music.py` (no samples, no licences needed).

- `scene/index.html` — the whole film as one page: open it with `?play` to watch it in a browser, or `?t=42` for one moment.
- `scene/shots/` — the app screens it uses, captured from the real app.
- `capture-screens.js`, `capture-screens-extra.js` — re-capture those screens (needs the API running and the web build served on port 8090).
- `music.py` — writes `music.wav`, timed to the film's chapters.
- `render.js` — renders every frame and encodes the MP4 with ffmpeg.

## Render

```bash
node brand/video/render.js --timeline
```

```bash
python3 brand/video/music.py brand/video/timeline.json brand/video/music.wav
```

```bash
node brand/video/render.js brand/video/ugent-brand-film.mp4
```

Needs Playwright's Chromium, ffmpeg and Python 3 with NumPy. Rendering takes several minutes.

To change the words, order or timing, edit the `SEGMENTS` list at the top of the script in `scene/index.html`.
